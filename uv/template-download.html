tzint is a C extension and is shipped as source: a built library holds for one platform and one Tcl series only. Unpack, then ./configure --with-tcl=DIR, make, make install.
 
Requirements
Tcl 8.5 or newer, including Tcl 9. Tk is not used.
 
Optional Libraries
Two, and they are not shipped with tzint.
libpng needed for the raster file formats of the file command. On Debian and Ubuntu the development package carries the headers: apt install libpng-dev. Build without it using --enable-filecmd=no, which leaves the bits, xbm, eps and svg commands.
zlib used together with libpng for the PNG output.
 
Included
The libzint backend by Robin Stuart is part of the source archive; nothing needs to be fetched separately. The version it carries is what ::tzint::Encode version reports.
